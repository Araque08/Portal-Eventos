# 🎉 Portal de Gestión de Eventos

#Aplicación web desarrollada con **React.js**, **TypeScript**, **Tailwind CSS** y **Firebase** para la administración y gestión de eventos tecnológicos. El proyecto permite a los usuarios registrarse, iniciar sesión, explorar eventos #disponibles e inscribirse, mientras que los administradores cuentan con un panel para crear, editar y eliminar eventos.

#Este proyecto fue desarrollado con el objetivo de fortalecer conocimientos en desarrollo frontend moderno, arquitectura basada en componentes, autenticación, consumo de servicios en la nube y buenas prácticas de desarrollo utilizando React.

## 🚀 Características

#- 🔐 Autenticación de usuarios con Firebase Authentication.
#- 👤 Registro e inicio de sesión.
#- 📅 Visualización de eventos disponibles.
#- ✅ Inscripción y gestión de eventos.
#- 🛠️ Panel de administración con operaciones CRUD para eventos.
#- 🎨 Interfaz moderna y responsiva con Tailwind CSS.
#- 🧭 Navegación entre páginas mediante React Router.
#- ⚡ Desarrollo con TypeScript para un código más seguro y mantenible.
#- 🧩 Arquitectura basada en componentes reutilizables.
#- ☁️ Almacenamiento de datos en Cloud Firestore.

## 🛠️ Tecnologías utilizadas

#- React.js
#- TypeScript
#- Tailwind CSS
#- React Router DOM
#- Firebase Authentication
#- Cloud Firestore
#- Vite
