Portal de Gestión de Eventos

Aplicación web desarrollada con React.js, TypeScript, Tailwind CSS y Firebase para la gestión de eventos tecnológicos.

El proyecto permite a los usuarios registrarse, iniciar sesión, explorar eventos disponibles e inscribirse, mientras que los administradores pueden crear, editar y eliminar eventos desde un panel de administración.

🚀 Características
Autenticación de usuarios con Firebase Authentication.
Registro e inicio de sesión.
Visualización de eventos disponibles.
Inscripción y gestión de eventos.
Panel de administración con operaciones CRUD.
Interfaces responsivas desarrolladas con Tailwind CSS.
Navegación mediante React Router.
Desarrollo con TypeScript para mayor seguridad y mantenibilidad.
Arquitectura basada en componentes reutilizables.
🛠️ Tecnologías
React.js
TypeScript
Tailwind CSS
React Router
Firebase Authentication
Cloud Firestore
